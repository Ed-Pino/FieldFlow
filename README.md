# S8-6-Team-8
FieldFlow — Centralized full-stack platform for field technical services. Java 17, Spring Boot 3 (REST, Security+JWT, JPA/Hibernate, PostgreSQL/H2, OpenAPI); React, TypeScript, Vite PWA. Role login (TECNICO/ADMIN), create/assign work orders, track state/history, checklists, photo evidence, notes, client signature for conformity, manage catalogs.
